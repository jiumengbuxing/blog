# 一级标题

段落之间用一个空行分隔。

第二段。_斜体_、**粗体** 和 `等宽字体`。无序列表长这样：

- 这一项
- 那一项
- 还有这一项

> 引用文字
> 就是这样写的。
>
> 只要你愿意，
> 它可以横跨多个段落。

## 二级标题

这是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

代码示例（缩进 4 个空格即可成为代码块）：

    # 再强调一遍……
    for i in 1 .. 10 { do-something(i) }

如你所猜，上面那块是缩进 4 空格得到的。不过更推荐用围栏代码块，复制粘贴更方便：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

你还可以给围栏块标注语言来获得语法高亮：

```python
import time
# 来，数到十！
for i in range(10):
    # （但别数太快）
    time.sleep(0.5)
    print(i)
```
