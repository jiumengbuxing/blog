欢迎来到你的新博客！这篇示范文章展示了写文章时最常用的排版元素，照着写就可以，也可以直接把它改成你的第一篇正式文章。

![配图：书桌上的写作场景](./assets/20261007-050038_markdown-guide_87545a.png)

## 普通段落

正文直接写就行。行内**加粗**、*斜体*、`行内代码`、[链接](https://github.com/jiumengbuxing)、[链接](https://www.bilibili.com/) 随手可用。https://www.bilibili.com/video/BV1FhHZ69ErG?t=1.0

## 列表

- 写文章：标题、摘要、分类、标签
- 插图：截图直接 Ctrl+V 粘贴进正文框
- 发布：点保存，然后双击「推送更新.bat」

1. 保存文章
2. 推送上线
3. 约两分钟后生效

## 代码块

三个反引号加语言名，自动语法高亮并带复制按钮：

```js
// 请求 GitHub API 的一个小例子
const res = await fetch("https://api.github.com/users/jiumengbuxing");
const user = await res.json();
console.log(`Hello, ${user.login}!`);
```
